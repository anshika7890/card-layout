# Web Technologies Card Layout

This is a simple card layout website built using HTML and CSS.  
It displays different web technologies like HTML, CSS, JavaScript, and Bootstrap using responsive cards.


## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- Clean and modern UI
- Responsive card layout
- Styled buttons
- Beginner-friendly project
